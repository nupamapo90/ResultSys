# ResultSys
提供されたソースコードをもとに、実際にこのシステムを操作する大会運営スタッフ（記録・計測担当者）の立場に立った概要説明をご案内します。

---

### 🏊 水泳記録会 タイム計測・リザルトシステム

このアプリは、水泳大会や記録会において「ストップウォッチ操作」から「記録の集計・ランキング作成・CSV出力」までをWebブラウザ上で完結できるタイム計測システムです。

配線作業や特殊な器具は不要で、PC1台（またはキーボード）があればすぐに現場で運用できます。

---

#### 💡 このアプリでできること（ユーザー視点のメリット）

**1. ワンタッチ＆キーボードで複数レーンを同時計測**

* メインタイマーをスタート（`Shift` + `S`）したら、各泳者のゴールやラップ時にテンキーの `0`〜`9` を押すだけで、全10レーン（0〜9レーン）のタイムを直感的に記録できます。


* 棄権（DNS）や失格（DSQ）も、`d` + レーン番号、`q` + レーン番号 のショートカットで即座に反映可能です。



**2. 押し忘れや誤操作の柔軟な現場補正**

* タッチの押し忘れがあっても、後から中間ラップの欠落挿入を行ったり、手入力で最終タイムを直接補正・適用したりすることができます。



**3. 組ごとの記録蓄積と自動ランク付け・進出判定**

* `Ctrl` + `Enter` でその組の記録を確定すると、自動的に次の中組へ進みデータが蓄積されます。


* 予選イベントではタイム順の自動ランキング生成に加え、「決勝進出」「B決勝進出」「スイムオフ発生（同着）」といった進出ステータスが自動判定されてバッジ表示されます。



**4. 欲しい形式で一閲覧＆CSVダウンロード**

* 表示は「全記録一覧」「スタートリスト形式」「ランキング形式」の3つのタブで即座に切り替え可能です。


* 蓄積された全組のデータはワンクリックで文字化けしにくいCSVファイルとして出力でき、集計作業や印刷用データへの引き継ぎがスムーズに行えます。



---

#### 🏁 1組あたりの基本的な操作の流れ

1. **競技情報の設定:** 画面上部でプログラムNo.、種目、距離（50m〜1500m）、ラップ単位、組数をセットします。


2. **スタート & 計測:** スタート音に合わせて `Shift` + `S`（またはスタートボタン）を押し、選手が通過・ゴールするたびに該当するレーン番号キー（`0`〜`9`）を押します。


3. **記録確定:** 全レーンの泳了後、`Ctrl` + `Enter`（または記録確定ボタン）を押すと記録が履歴に保存され、組数が自動で「+1」カウントアップされます。


4. **出力:** 全レース終了後、画面下の「CSVダウンロード」ボタンを押してデータを保存します。
